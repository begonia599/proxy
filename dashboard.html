上游服务商

保底来源

每个服务商 = base_url + key + 协议格式。新建后点「管理模型」拉取上游模型、勾选加入大组库存并设价。在「分组」里把大组里的模型映射成对外逻辑名。

分组

逻辑名映射

从大组库存里挑模型，给每个起一个对外逻辑名（如 sonnet / opus）。同一逻辑名可挂多个上游，手动切「主用」即可零感知换上游。proxy key 绑定一个分组作为可用模型白名单。

分组列表

选择一个分组

透传服务商 未命中映射的模型原样发给它（该服务商全量放行）；选「无」则仅允许下方已映射的逻辑名。
